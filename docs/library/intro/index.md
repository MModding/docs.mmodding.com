# Concept Overview

The MModding Library is the standard used by MModding mods.
It provides multiple modules, all focused on different stuff to help modders through their modmaking process.

Some parts of the documentation are focused to be beginner-friendly, whereas some others are not.
Watch the tone of the documentation page! You'll know when that's hell you'd be walking into.

Reading the `core` module documentation can be useful, as stuff from it can be reused
in the documentation of other modules.

I would also recommend to look at the [Official Fabric Documentation](https://docs.fabricmc.net/develop), as it
provides very useful documentation for subjects that are expanded with the library, or just other stuff in general
that this documentation could not cover, as not part of the targeted subjects.
